# enhance — 提示词增强兜底（✨ 浮层失效期间）

zcode-prompt-enhance 项目在 ZCode 输入框旁注入 ✨ 按钮做一键增强；注入丢失
（ZCode 升级后常见）或浮层定位失效期间，用本技能走命令行链路完成同一件事。

## 使用前提

- 增强脚本位于仓库部署路径（默认 `F:\AI\Zcode\zcode-prompt-enhance`，
  环境变量 `ZPE_HOME` 可覆盖）：`tools/enhance-cli.mjs`。
- 脚本复用注入路径的同一套 core（provider 路由 + 超时 + 错误码归一化），
  走 `config.json` 的默认路由，不跟随会话模型。

## 步骤

1. 向用户取得草稿原文（要发给 AI 的原始提示词）。缺失信息不臆造。
2. 草稿较长时先写入系统临时目录的文件（不要写进仓库），避免命令行转义问题。
3. 执行：

   ```bash
   node "<仓库>/tools/enhance-cli.mjs" --file <草稿临时文件>
   ```

4. 把 stdout 的增强结果放进代码块原样展示，并提示用户手动复制回输入框
   （无浮层时无法原地回填）。
5. 退出码 1 时把 stderr 的中文错误原样转告，最多重试一次。

## 边界

- 不修改增强结果的内容；不尝试直接写入 ZCode 输入框。
- 脚本缺失/路径无效时如实说明安装方式（见仓库 README 的「/enhance 兜底命令」节）。
