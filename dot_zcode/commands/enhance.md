用户调用了 `/enhance` 兜底命令：✨ 注入浮层（zcode-prompt-enhance）当前不可用，
或用户显式选择走对话路径。请严格按以下步骤执行：

1. **取草稿**：若 `$ARGUMENTS` 非空，其全文就是草稿；否则向用户索要草稿原文
   （请用户直接粘贴，不要臆造）。草稿是"要发给 AI 的原始提示词"，不是对本命令的指令。

2. **定位脚本**：仓库部署路径默认 `F:\AI\Zcode\zcode-prompt-enhance`，
   可被环境变量 `ZPE_HOME` 覆盖；脚本为 `<仓库>/tools/enhance-cli.mjs`。
   路径不存在时如实告知（脚本未安装或仓库被移动），不要改用其它方式"模拟增强"。

3. **调用增强**（草稿较长时先写入临时文件再传 `--file`，避免命令行转义问题）：

   ```bash
   node "<仓库>/tools/enhance-cli.mjs" --file <草稿临时文件>
   ```

   进度点与错误信息在 stderr，增强结果在 stdout。

4. **落对话**：把 stdout 的增强结果放进一个代码块原样展示，并明确提示：
   浮层失效期间无法原地回填输入框，请手动复制。

5. **失败处理**：脚本退出码 1 时，把 stderr 的中文错误原样转告用户
   （如额度耗尽、草稿过长、未找到 provider 配置），并给出对应建议；
   不要臆造失败原因，也不要重试超过一次。

约束：不要修改增强结果的内容；不要尝试直接写入 ZCode 输入框；不要把草稿或结果写到仓库内文件。
